# Hi, I'm Gwenaëlle 👋

I'm a frontend-focused fullstack developer based in the Paris area. I came to web development during the COVID lockdown after some time in video editing, turns out the attention to detail and sense of composition translate pretty well 🙃
 
Since then I've completed a frontend developer training program at OpenClassrooms while working as a frontend developer, and went on to spend two years as a fullstack developer afterward.
 
This GitHub mainly features projects made during my training program, but the tech stack below includes what I learned to use in the other projects I made in my different positions.
 
I'm currently open to new opportunities.
